# booleanmaths-rn-sdk

Booleanmaths react native sdk to track user events and attribution in mobile apps.

## Installation


```sh
npm install booleanmaths-rn-sdk
```


## Usage


```js
import { multiply } from 'booleanmaths-rn-sdk';

// ...

const result = multiply(3, 7);
```
